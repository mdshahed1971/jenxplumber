# Jenx Plumbing Premium

Build a premium, high-end plumbing contractor website for **Jenx plumber** using **React + Vite + Tailwind CSS**.

The website must feel custom-designed, expensive, modern, cinematic, and human-made — NOT like a generic plumbing template.

## TECHNICAL REQUIREMENTS

* Use React + Vite + TypeScript.
* Use Tailwind CSS.
* Keep the implementation lightweight to minimize Lovable credit usage.
* Avoid unnecessary libraries and dependencies.
* Use Framer Motion only where it materially improves animations.
* Use Lucide React for icons if icons are needed.
* Do not rebuild the project unnecessarily if the existing React/Vite/Tailwind structure already works.
* Keep components reusable and clean.
* Fully responsive across desktop, tablet, and mobile.
* Test carefully at approximately 320px, 375px, 390px, 430px, tablet, and desktop widths.
* No horizontal overflow.
* No broken layouts, clipped text, or console errors.
* Prioritize performance and smooth animations.
